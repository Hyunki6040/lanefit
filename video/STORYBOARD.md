# LaneFit 숏폼 3편 · 씬 구성

세로 9:16, 1080x1920, 30fps. 30초~1분 길이의 숏폼 세 편입니다.

| 편 | 길이 | 중심 | 목소리 |
|---|---|---|---|
| A 「아빠의 깜빡이」 | 45초 | 가족과 안전 | 여성 아나운서 |
| B 「도로는 이미 알고 있다」 | 48초 | 실데이터, 도로 카메라, AI | 남성 아나운서 |
| C 30초 컷 | 30초 | B편을 줄인 훅 | 남성 아나운서 |

카메라는 먼 곳에서 가까운 곳으로 내려옵니다. 위성 → 드론 → 관제실 → 데이터 → 도로 카메라 분석 → 내 차와 차선 → 사람 → 앱 화면.

컷 목록의 원본은 `src/specs.ts`입니다. 시간은 내레이션 단어 시각(`public/voice/*.words.json`)에 맞춥니다. 이 문서와 다르면 코드가 맞습니다.

## 사실 표기 원칙

엔딩을 제외한 모든 장면의 왼쪽 위에 화면의 출처 등급을 적습니다.

| 등급 | 화면 표기 | 뜻 |
|---|---|---|
| 구현 | `Pleos Connect 에뮬레이터 실행 화면` | 앱을 에뮬레이터에서 녹화한 화면 |
| 데이터 | `한국도로공사 공개 데이터 · 2026-11-10 · 경부선 1지점` | `scripts/analyze_avc.py` 결과 |
| 분석 | `도로 CCTV 영상 AI 분석 · 연출 영상 (AI 생성)` | 도로 카메라 영상 흐름 분석. 상자와 흐름 막대는 `scripts/analyze_cctv.py`가 계산한 값 |
| 연출 | `연출 장면 (AI 생성)` | Higgsfield로 만든 인물·도로 장면 |
| 예시 | `연출 장면 (AI 생성) · 앱은 예시 도로 값으로 동작` | 내 차와 옆 차로 비교 장면 |

- 인물은 모두 AI가 만든 가상 인물입니다. 실제 차량 엠블럼, 번호판, 제3자 로고가 보이는 컷은 쓰지 않습니다.
- 도로 카메라 장면은 AI로 만든 영상입니다. 국가교통정보센터의 실제 CCTV 영상은 무단 복제·배포를 금지하는 사이트 정책에 따라 넣지 않습니다.
- 도로 카메라 장면 위의 상자와 흐름 막대는 그림이 아니라 `scripts/analyze_cctv.py`가 그 컷에서 계산한 값입니다(`src/data/cctv_boxes.json`). 화면상 상대 속도이고 km/h가 아닙니다.
- 엔딩은 로고 대신 글자로 씁니다. `LaneFit · 레인핏` / `덜 바꿔도, 늦지 않습니다` / `현대자동차그룹의 차세대 인포테인먼트 시스템` / `Pleos Connect 차선 비서` / `Pleos SDK로 차량과 연결됩니다` / `인물·도로 장면은 AI 생성 연출 · 앱 화면은 에뮬레이터 실제 녹화`.

## C편 30초 컷

B편 내레이션에서 네 문장만 씁니다. 위성(0–1.5) → 드론(–3.9) → 관제실(–6.4) → 81.5%(–11.4) → 도로 카메라 분석(–14.9) → 내 차와 옆 차로(–17.1) → 레버(–19.4) → Stay 카드(–23.2) → "2분 빨라요"(–26) → 엔딩(–30). 내레이션이 없는 구간은 자막과 효과음으로 채웁니다.

## 소스

| 종류 | 내용 | 위치 |
|---|---|---|
| 앱 화면 | 에뮬레이터 녹화 2개(차량 신호 주행, 66초 시뮬레이션). 아래쪽에 카드 문구를 확대해 다시 보여 줍니다 | `public/footage/` |

| 데이터 | AVC 차로별 속도, 도로 카메라 컷의 분석 상자 | `src/data/` |

`public/` 아래 미디어는 저장소에 넣지 않습니다. 완성본은 `docs/media/video/`에 있습니다.

## 만들기

```bash
cd video && npm install
npx tsc --noEmit
npx remotion render src/index.ts LaneFitB out/B.mp4   # LaneFitA, LaneFitC 도 같다
ffmpeg -i out/B.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k lanefit-short-B.mp4
```
